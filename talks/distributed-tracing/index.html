Distributed tracing

Florian Garcia published on April 05, 2017
1 min, 75 words

Categories: French Observability Tracing Distributed Systems Java Spring

In this talk I explain what distributed tracing is and how you can use it to monitor your distributed systems. The example is using Spring Cloud Sleuth and Zipkin.


The code repository is available in GitHub.

This is one of my first talk and at one of the biggest French conference. I was quite nervous, I had some language tics but it was a great experience.
