In this talk with <a href="https://www.linkedin.com/in/guillaume-lannebere-51a17183/" target="_blank">Guillaume Lannebere</a>, we explain what event driven architectures are and how you can use them to build scalable and resilient systems.
This talk explain how we built such architecture using AWS SNS and SQS and all the tooling around it to secure and monitor the system.
